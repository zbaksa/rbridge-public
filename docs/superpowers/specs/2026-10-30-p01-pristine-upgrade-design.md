## Approach
Use a separate original-P01-only pristine handoff. Never relax NativeV3PeerAuthority, adopt retained history, reset a namespace or silently overwrite old startup. General retained-history migration is outside this work. All preimages and writer exclusion must be verified again at apply; owner observations only select the candidate route.

Native and Linux must reject any events.ndjson, nonempty results/peer journal, uncertainty, partial/upload/query/STOP state, unexpected entry, link/reparse, changed snapshot or active writer. Existing Linux empty writer.kernel.lock files are identity metadata: acquire the same inode gates and preserve them. Old config/marker and existing pre-P01 backup remain durably preserved in transaction backups. Same root inode, original scope/identity/anchor and unrelated R6/D0/NIM state remain untouched. Publication is journaled, recoverable and pair-verified; partial or unknown states remain blocked. No automatic retry of uncertain effects.
