# Linux scope STOP barrier

Implement two fixed CLI operations through the existing private Linux peer gate. The first valid scope STOP request is an immutable additive journal admission fence even when the channel or optional capability is unavailable. Exact old command/chunk replay and collision checks remain available; new staging, command admission and ordinary read queries stop. Raw quiescence control is dispatched before retained passive reconciliation; queued EXECUTE never drains after the fence.

Submission is always RBRIDGE_SCOPE_STOP_SUBMISSION_V1/BLOCKED. Readback is RBRIDGE_SCOPE_STOP_OBSERVATION_V1 with the actual stored request and original record. Every read freshly derives PASS from a live private channel, current query/pins, complete factual report, stopped/sealed worker, zero unresolved counters, equal worker/Native/Linux durable event tail, and equal complete inventories. Linux computes full command/result evidence and exact-request terminal reconciliation, then cross-checks the complete result journal including NULL/orphan reservations. Transfers and queued EXECUTE block proof. Expired ordinary read queries are retained and classified expired, never active proof. Missing fence reads do not initialize history. No scope, executable, root, authority or message budget is expanded.

Qualification: real temporary private files, fixed CLI field negatives, raw stdio transport, request/query replay/collision, report immutability, stale channel/query, late event, full inventory and pending work negatives.
